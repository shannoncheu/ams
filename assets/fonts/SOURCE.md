# Bundled Noto Sans SC

Unmodified variable font, Google Fonts / Adobe Noto Sans SC.

Source: https://github.com/google/fonts/tree/main/ofl/notosanssc

Font: https://raw.githubusercontent.com/google/fonts/main/ofl/notosanssc/NotoSansSC%5Bwght%5D.ttf

License: SIL Open Font License 1.1, included in OFL.txt.

SHA256: `a3041811a78c361b1de50f953c805e0244951c21c5bd412f7232ef0d899af0da`

The single wght variable font supplies Regular (400), Medium (500) and Semibold (600). It is embedded and registered in GPUI once at application startup. No system font installation is required.
